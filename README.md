# MemeMeV1

Meme editor for iOS, built in 2015 as a Udacity iOS course project.

## What it does

- Pick an image from the photo album or take one with the camera.
- Add top and bottom captions in the classic meme style.
- Share the finished meme through the system share sheet.

The second version, with a list and a grid of sent memes, is in
[MemeMeV2](https://github.com/baitcode/MemeMeV2).

## Build

Open `MemeMeV1.xcodeproj` in Xcode. There are no third-party dependencies.

## Status

Written in Swift 2, so it will not compile with a current Xcode without
migration.
